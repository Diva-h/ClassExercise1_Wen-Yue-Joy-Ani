# Class Exercise 1 – Multivariate Analysis for Social Scientists

This repository is part of the Multivariate Analysis course at the University of Milan.

## 📂 Folder Structure
- `src/` – All R scripts (import, regression, plots)
- `output/` – Final plots and report
- `raw_data/` – Original datasets (not pushed!)
- `recoded_data/` – Cleaned data

## 👩‍💻 Team Members & Roles
- **Wen**: Import, clean, run regression
- **Yue**: Create plot, write report
- **Ani (me)**: GitHub setup, folder structure, README, integration

## ▶️ How to Run This Project
1. Run `src/Ce1_Part1_dataimport_cleaning_regression.R`
2. Run `src/Boxplot.R`
3. View plot in `/output/boxplot_satisfaction.png`
4. Report is generated via `report.Rmd` (to HTML)

## 🔁 GitHub Flow
- Each member opens issues, branches, pull requests
- All changes are made through branches and merged via pull requests (PRs)
